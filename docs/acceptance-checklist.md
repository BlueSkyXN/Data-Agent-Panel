# 验收清单

## 平台功能

- [ ] 可登录并获取 Token。
- [ ] 密码以哈希形式存储。
- [ ] 可注册、发布、停用 Agent。
- [ ] 可配置 Agent 风险等级和人工审批要求。
- [ ] 可进行智能问数并返回答案、表格、图表、SQL。
- [ ] 可创建深度分析任务。
- [ ] 高风险分析任务进入审批流。
- [ ] 可查看 Trace、Trace Steps、SQL Runs、Tool Calls。
- [ ] 可维护数据源、数据集、字段、指标、同义词。
- [ ] 可绑定知识库。
- [ ] 可生成并管理报告版本。
- [ ] 可维护评测集并运行评测。
- [ ] 可查看审计日志和平台统计。

## 安全

- [ ] 未登录无法访问业务 API。
- [ ] 普通用户不能访问管理接口。
- [ ] 普通用户不能查看数据源连接配置。
- [ ] 普通用户只能看到授权数据集。
- [ ] 敏感字段被脱敏。
- [ ] 危险 SQL 被 SQL Guard 拦截。
- [ ] SQL 引用非授权表被拦截。
- [ ] 外部 Agent endpoint 不在 allowlist 时被拒绝。
- [ ] 审计日志记录请求 ID、用户、动作、对象、时间。

## 运维

- [ ] `/api/health/live` 可用。
- [ ] `/api/health/ready` 可用。
- [ ] Docker healthcheck 正常。
- [ ] 日志包含 request_id。
- [ ] 备份恢复流程已验证。
- [ ] 生产环境已设置强密钥与 CORS 白名单。

## V0.3 完整 Agent + Codex 验收项

- [ ] Agent 市场显示不少于 10 个内置 Agent。
- [ ] 总控 Agent 可自动路由到 销售、工单、风险、面板、语义、数据质量和 Codex。
- [ ] 数据能力页可查看数据集、运行画像、执行只读 SQL、运行业务规则。
- [ ] 分析面板页可物化经营总览面板，并展示图表和表格。
- [ ] 语义中心可展示指标、术语、查询模板和覆盖率。
- [ ] Codex 工作台可创建、审批、mock 派发任务，并生成 handoff 文件。
- [ ] `scripts/full_agent_smoke_test.py` 通过。
- [ ] 所有 Agent 调用都有 Trace，且 SQL/工具/权限步骤可回放。
