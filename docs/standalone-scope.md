# 独立平台范围说明

本版本是**单独的数据智能体平台**，不绑定任何既有项目、业务中台或质量场景。系统内置的销售、工单、营销、商品和经营日度指标仅用于通用演示与回归测试。

## 保留能力

- Web 工作台
- Agent Gateway
- 内置通用 Agent
- 数据目录、指标字典、语义术语、查询模板
- 只读 SQL Workbench 和 SQL Guard
- 数据画像、数据质量、分析面板
- Trace、审计、反馈、评测中心
- Codex 工程任务嵌套
- Hugging Face Docker Space 部署

## 独立版内置通用域

| 通用域 | 说明 |
|---|---|
| 销售订单 | 收入、订单、渠道、区域、品类、商品、客户分层 |
| 客户工单 | 工单类型、根因、严重度、状态、客户服务风险 |
| 营销活动 | 花费、曝光、点击、转化、活动收入、ROI |
| 商品目录 | 商品、品类、价格、成本、供应商 |
| 经营日度指标 | 收入、订单、未关闭工单、转化率、风险分 |

## 环境变量

独立版统一使用 `DAP_` 前缀，例如：

```env
DAP_APP_ENV=hf-space
DAP_HF_SPACE=true
DAP_SECRET_KEY=<强随机密钥>
DAP_OPS_TOKEN=<运维只读 token>
DAP_CODEX_MODE=mock
```

## 推荐首个真实接入场景

建议先接一个通用业务域，例如：

```text
订单 + 商品 + 渠道 + 客户工单 + 营销活动
```

先准备 50-100 个真实业务问题，再配置数据集、字段语义、指标口径、权限和评测集。
