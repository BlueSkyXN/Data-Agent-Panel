# UI 与功能地图

本版本将界面升级为 14 个生产化页面：

1. **控制塔**：总体状态、Agent/Trace/SQL/Codex 指标、关键链路、快捷分析入口、任务 composer、最近会话/报告继续工作面板和最近任务队列 Trace 下钻。
2. **Agent Studio**：按能力目录选择 Agent，支持名称/ID/Adapter 搜索、能力类型和风险筛选，右侧 inspector 查看风险、版本、知识绑定，并直接进入问数/研究。
3. **智能问数**：左侧场景问题、可按标题和消息内容搜索/重命名/归档/项目筛选的会话库和 Project-style 工作包，中间对话与图表/表格/报告，右侧 Trace 证据链和可编辑工作 Canvas；composer 显示 Agent/数据集/工具/证据/工作包上下文，并支持临时对话模式（不写入会话库或消息历史，但保留 Trace 和 audit）、`+` 添加上下文菜单快速加入数据集、知识库、报告、本地文本/Markdown/CSV/JSON 资料、切换记忆边界、带 Canvas 提问和捕获/应用工作包，支持 `/` 工具菜单直达指标解释、图表方案、SQL 草稿、Canvas 大纲、报告要点、工作包应用/捕获、深度研究、Codex 任务和数据资产。工作包支持搜索并加入数据集、知识库和报告资产，可逐项打开或移除上下文，可加入多个来源会话并在会话库中只看项目会话，可保存/加载/删除本地项目预设，可设置项目内/默认记忆边界，可把多来源会话随 `context_pack.session_ids` 提交给问数请求，可把 Canvas 草稿随 `context_pack.canvas_markdown` 提交给问数请求，可把知识库随 `context_pack.knowledge_base_ids` 一起提交给问数请求，可把浏览器本地读取的资料随 `context_pack.local_files` 提交给问数请求且不作为后端上传/存储功能，并提供解释指标、生成图表、打开数据资产、转深度研究、创建 Codex 任务、发送中停止生成、用户问题编辑/重问/分支/写入 Canvas/复制、会话 Brief 生成/复制/下载、回答写入/追加 Canvas、提取下一步、回答后续追问建议、捕获上下文、应用工作包、生成分析大纲/SQL 草稿/报告要点、Canvas Markdown 加粗/斜体/标题/项目列表/编号列表格式化、Canvas 选区润色/补证据/压缩/展开/追问、本地版本回退、版本变化对比、保存报告草稿和下载 Markdown 的快捷动作。
4. **深度研究**：研究 brief、可审批计划、历史研究任务队列、证据 Trace、报告草稿入口和取消/刷新任务。
5. **分析面板**：物化经营总览面板、创建面板 brief、添加 Widget，并通过 SQL Guard 预校验后刷新面板证据。
6. **数据能力**：可搜索/筛选的数据资产库、数据集详情、字段/指标、只读 SQL Workbench、数据画像、业务规则运行、质量历史复核，以及从数据集直接进入问数/研究/Codex 治理任务的上下文动作。
7. **语义中心**：指标、字段、术语、查询模板、覆盖率、搜索/业务域筛选和受权限保护的术语补全入口。
8. **Codex 工作台**：预检 CLI/SDK、安装说明、任务创建、审批、派发和产物查看。
9. **报告中心**：AI 生成报告资产库、搜索/状态/类型筛选、报告 Canvas、版本、证据、来源会话回跳、Trace 复核，以及继续追问/深度研究/Codex/审计上下文动作。
10. **知识库**：知识库注册、名称/ID/Adapter/绑定 Agent 搜索、后端/类型筛选、Adapter 绑定推断、版本入口、Agent 引用视图，以及知识问答/语义资产/审计/Codex 接入动作。
11. **评测中心**：可搜索/按业务域/标签筛选的评测资产库、用例卡片回放、创建评测集、添加回放用例、运行 Agent 回归、从结果下钻 Trace，并可把评测用例直接转问数或 Codex 修复任务。
12. **审计日志**：平台关键动作审计、筛选、事件详情、Trace pivot，以及事件分析/相关对象/Codex 加固动作。
13. **Ops 控制面**：HFS 健康、只读诊断入口、运行态摘要和安全边界说明。
14. **Admin 控制面**：管理员用户、角色权限、运行配置、平台统计和最近审计事件。

顶栏全局指挥入口支持搜索页面、Agent、数据集、指标、报告资产和会话历史，可直接进入报告 Canvas 或恢复来源对话。

界面设计遵循“业务层可读、专业层可查”的原则：业务用户看答案、图表和建议；数据/平台人员通过 Trace 查看 SQL、工具调用、权限、输出和错误。
