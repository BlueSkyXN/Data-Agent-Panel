# UI 与功能地图

本版本将界面升级为 14 个生产化页面：

1. **控制塔**：总体状态、Agent/Trace/SQL/Codex 指标、关键链路、快捷分析入口和任务 composer。
2. **Agent Studio**：按能力目录选择 Agent，右侧 inspector 查看风险、版本、知识绑定，并直接进入问数/研究。
3. **智能问数**：左侧场景问题，中间对话与图表/表格/报告，右侧 Trace 证据链。
4. **深度研究**：研究 brief、可审批计划、证据 Trace、报告草稿入口和取消/刷新任务。
5. **分析面板**：物化经营总览面板，展示指标卡、Top 图和风险图。
6. **数据能力**：数据目录、数据集详情、字段/指标、只读 SQL Workbench、数据画像、业务规则运行。
7. **语义中心**：指标、字段、术语、查询模板、覆盖率和受权限保护的术语补全入口。
8. **Codex 工作台**：预检 CLI/SDK、安装说明、任务创建、审批、派发和产物查看。
9. **报告中心**：AI 生成报告资产、报告 Canvas、版本、证据和 Trace 复核。
10. **知识库**：知识库注册、Adapter 绑定推断、版本入口和 Agent 引用视图。
11. **评测中心**：评测集运行和结果展示。
12. **审计日志**：平台关键动作审计、筛选、事件详情和 Trace pivot。
13. **Ops 控制面**：HFS 健康、只读诊断入口、运行态摘要和安全边界说明。
14. **Admin 控制面**：管理员用户、角色权限、运行配置、平台统计和最近审计事件。

界面设计遵循“业务层可读、专业层可查”的原则：业务用户看答案、图表和建议；数据/平台人员通过 Trace 查看 SQL、工具调用、权限、输出和错误。
