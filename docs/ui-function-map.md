# UI 与功能地图

本版本将界面升级为 12 个生产化页面：

1. **控制塔**：总体状态、Agent/Trace/SQL/Codex 指标、关键链路、快捷分析入口。
2. **Agent Studio**：按类型筛选 Agent，查看风险、状态、描述，并直接试运行。
3. **智能问数**：左侧场景问题，中间对话与图表/表格/报告，右侧 Trace 证据链。
4. **深度研究**：创建研究任务、审批计划、查看多 SQL 分析和报告草稿。
5. **分析面板**：物化经营总览面板，展示指标卡、Top 图和风险图。
6. **数据能力**：数据目录、只读 SQL Workbench、数据画像、业务规则运行。
7. **语义中心**：指标、字段、术语、查询模板和覆盖率。
8. **Codex 工作台**：预检 CLI/SDK、安装说明、任务创建、审批、派发和产物查看。
9. **报告中心**：AI 生成报告资产。
10. **知识库**：知识库注册、绑定和版本入口。
11. **评测中心**：评测集运行和结果展示。
12. **审计日志**：平台关键动作审计。

界面设计遵循“业务层可读、专业层可查”的原则：业务用户看答案、图表和建议；数据/平台人员通过 Trace 查看 SQL、工具调用、权限、输出和错误。
