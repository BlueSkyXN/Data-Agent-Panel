# 评测体系

## 1. 评测对象

```text
Agent 版本
Adapter 版本
语义配置版本
知识库版本
模型版本
Prompt 版本（由业务智能体团队维护）
```

## 2. 评测指标

| 指标 | 说明 |
|---|---|
| 意图识别准确率 | 是否识别为问数、知识、分析、报告 |
| 路由准确率 | 是否调用正确 Agent |
| SQL 正确率 | 表、字段、过滤、聚合是否正确 |
| 数值一致率 | 与人工 SQL/BI 报表对比 |
| 图表可用率 | 图表类型、维度、指标是否合理 |
| 引用准确率 | 是否引用正确知识和版本 |
| Trace 完整率 | 是否有 SQL、数据源、知识引用、执行步骤 |
| 权限正确率 | 是否发生越权或敏感字段泄漏 |
| 报告可用率 | 分析框架、结论、建议是否可复核 |
| 人工采纳率 | 用户是否采纳输出 |

## 3. 最小评测集

```text
50 个真实业务问题
20 个标准 SQL
10 个标准图表
5 个标准报告样例
10 条业务规则或知识引用样例
10 个失败案例
```

## 4. 操作流程

1. 在评测中心创建 eval_set。
2. 导入 eval_cases。
3. 选择 Agent 运行 eval_run。
4. 查看 eval_results 和对应 Trace。
5. 人工标注错误类型。
6. 形成版本对比。
