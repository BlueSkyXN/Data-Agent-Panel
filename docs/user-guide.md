# 用户使用手册

1. 登录平台后，先进入**工作空间**，为一个持续问题创建空间并写明目标。
2. 在空间内保存 Canvas、结论笔记和待办；关联数据集、会话、报告或 Trace 时，系统仍按每项资产的原生权限过滤。
3. 选择“继续分析”进入智能问数。当前空间会作为一次服务端校验过的上下文加入请求；它不会让成员获得原本无权读取的资产。
4. 在 Agent 市场选择 Agent，输入业务问题。
5. 查看答案、图表、表格，并在右侧 Trace 查看 SQL、数据来源和执行步骤。
6. 对结果打反馈：正确、部分可用、有误、需复核。
7. 需要长报告时进入深度研究页创建任务；计划会先遵循审批状态。
8. 在报告中心查看和复核保存的报告草稿。工作空间的 Canvas、笔记和待办正文不会写入审计摘要或 Trace。
